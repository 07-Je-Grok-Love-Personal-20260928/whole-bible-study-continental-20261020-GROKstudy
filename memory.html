🪝一、口诀：先挂钩

1.📋 66 卷一句话 + 必背经文

📋 66 卷速查：一句话精髓 + ★ 必背经文（点开）
#书卷一句话精髓★ 必背
1创世记万有与救赎的“开端之书”：神藉话语创造、人背约堕落、神以应许开启恩典之约，并拣选亚伯拉罕一家作为祝福万国的管道。创1:1
2出埃及记救赎之书：耶和华施行大能救赎，把奴隶变为祭司的国度，在西奈立约，并亲自住在他们中间（会幕）。出20:2
3利未记圣洁之书：圣洁的神如何住在不洁的百姓中？——藉着献祭、祭司与赎罪日。利17:11
4民数记旷野之书：不信的一代倒毙旷野，信实的神却保守新一代走到应许地门口。民6:24-26
5申命记约的重申之书：摩西临终前在摩押平原向新一代讲道三篇，呼召他们“爱耶和华你的神”。申6:4-5
6约书亚记得地之书：神信实地实现对列祖的应许，带领以色列进入、征服并分配迦南地。书1:9
7士师记沉沦之书：没有王、各人任意而行的以色列陷入“犯罪—受压—呼求—拯救”的循环，而且一圈比一圈更深。士21:25
8路得记救赎至亲之书：黑暗士师时代里一段忠信与恩慈（hesed）的故事，引出大卫的家谱。得1:16
9撒母耳记上王权之书（上）：从士师到君王的转折——撒母耳兴起，扫罗被立又被弃，大卫受膏而受苦。撒上16:7
10撒母耳记下王权之书（下）：大卫作王、耶路撒冷成为京城、神与大卫立永约；随后大卫犯罪，家中刀剑不离。撒下7:16
11列王纪上从荣耀到分裂：所罗门建殿的高峰，王心偏离，国分为二；以利亚在巴力崇拜的黑暗中为耶和华作见证。王上18:21
12列王纪下两国相继灭亡：北国722年亡于亚述，南国586年亡于巴比伦；但约雅斤出狱一线微光，暗示大卫的灯没有熄灭。王下6:16
13历代志上归回之民的“身份证”：从亚当到大卫的家谱，以大卫与圣殿敬拜为中心重述历史。代上29:11
14历代志下从所罗门献殿到古列谕令：犹大诸王以“寻求耶和华”为兴衰标准，结束于“回去建殿”的邀请。代下7:14
15以斯拉记归回与重建：神激动古列的心，余民回归建殿；以斯拉带领律法上的改革。拉7:10
16尼希米记建城墙与建百姓：尼希米以祷告和行动在52天内修完耶路撒冷城墙，与以斯拉一同带领立约更新。尼8:10
17以斯帖记隐藏的神之书：全书未提“神”字，但神的护理处处可见，保守散居波斯的犹太人免遭灭族。斯4:14
18约伯记义人受苦之书：撒但控告、朋友误判、约伯呼求，最终神从旋风中显现——问题不是“为什么”，而是“谁”。伯19:25
19诗篇教会的诗歌与祷告书：一百五十篇诗涵盖赞美、哀歌、感恩、悔罪、王诗与智慧诗，是“整本圣经的缩影”（路德）。诗1:2
20箴言敬畏耶和华是智慧的开端：父亲教导儿子在日常生活中行在智慧的道路上。箴1:7
21传道书“日光之下”的诚实之书：一切如烟似雾（hevel），唯有敬畏神、谨守他的诫命是人当尽的本分。传12:13
22雅歌歌中之歌：在婚约中男女纯洁而热烈的爱；更深层地，映照耶和华与他子民（基督与教会）的爱。歌8:6
23以赛亚书旧约的“福音书”：圣者以色列的审判与安慰，从受苦的仆人到新天新地。赛9:6
24耶利米书流泪先知的书：在犹大灭亡前四十年呼召悔改，宣告七十年被掳，并预告“新约”。耶29:11
25耶利米哀歌废墟上的哀歌：五首离合体诗，为耶路撒冷的毁灭哭泣，中心宣告“耶和华的慈爱永不断绝”。哀3:22-23
26以西结书神的荣耀离开与归回：被掳中的祭司先知看见宝座异象，宣告审判、复活与新圣殿。结36:26
27但以理书万国之上的至高者：被掳宫廷中的忠信，以及四大帝国被“人子”永远国度取代的异象。但7:14
28何西阿书受伤丈夫之爱：先知娶淫妇歌篾，演出耶和华对不忠以色列的审判与不止息的爱。何6:6
29约珥书耶和华的日子：蝗灾是审判的预表，呼召撕裂心肠的悔改，并应许圣灵浇灌凡有血气的。珥2:28
30阿摩司书公义如大水滚滚：南国牧人到北国伯特利，宣告对富足而不义的宗教的审判。摩5:24
31俄巴底亚书旧约最短的书：以东因幸灾乐祸、协助攻击兄弟雅各而被审判；“国度要归耶和华”。俄4
32约拿书逃跑的宣教士：神差约拿向仇敌之城尼尼微传悔改，显明神的怜悯临及外邦，也揭露先知自己的狭隘。拿2:9
33弥迦书“谁像你？”——审判撒玛利亚和耶路撒冷，应许伯利恒出君王，并宣告神赦罪的怜悯。弥6:8
34那鸿书尼尼微的第二篇信息：约拿时的悔改已过去，神必审判残暴的亚述——这是给犹大的“安慰”（那鸿=安慰）。鸿1:7
35哈巴谷书先知与神的对话：从“为什么？”到“义人必因信得生”，再到“我要因耶和华欢欣”。哈2:4
36西番雅书耶和华的大日临近：普世审判之后，神在锡安中间因你欢欣喜乐而歌唱。番3:17
37哈该书先建神的殿：四篇日期精确的信息，催促归回者停止只顾自己天花板的房屋，重建圣殿。该2:9
38撒迦利亚书小先知中的“启示录”：八个夜间异象、谦和的君王骑驴而来、被扎的牧人与终末的胜利。亚9:9
39玛拉基书旧约的最后一句话：在冷淡的归回群体中，以辩论式问答揭露敷衍的敬拜，并预告“立约的使者”与以利亚的来临。玛3:6
40马太福音君王之福音：耶稣是亚伯拉罕的后裔、大卫的子孙，应验律法和先知的弥赛亚君王，建立天国并差遣门徒使万民作门徒。太28:19-20
41马可福音仆人之福音：节奏急促（“立刻”40余次），展示神的儿子的权柄，并揭示他来是为了服事并舍命作多人的赎价。可10:45
42路加福音人子与救主之福音：按次序详细考查，显明耶稣是寻找拯救失丧之人的救主，福音临到贫穷、妇女、外邦人与罪人。路19:10
43约翰福音道成肉身之福音：七个神迹（记号）与七个“我是”，为要叫人信耶稣是基督、是神的儿子，并因信他的名得生命。约1:1
44使徒行传升天基督藉圣灵继续作工：福音从耶路撒冷、犹太全地、撒玛利亚，直到地极。徒1:8
45罗马书福音的系统宣告：神的义藉信耶稣基督显明——罪、称义、成圣、拣选、生活，是宗教改革的“钥匙”。罗3:23-24
46哥林多前书问题教会的十字架答案：分党、淫乱、诉讼、婚姻、祭偶像之物、敬拜秩序、属灵恩赐、复活——一切都在“钉十字架的基督”下得到纠正。林前15:3-4
47哥林多后书软弱中的能力：保罗为自己的使徒职分辩护——瓦器里有宝贝，新约的执事是叫人得生的。林后5:21
48加拉太书基督徒自由的大宪章：人称义不是因行律法，乃是因信耶稣基督；任何加添都是“别的福音”。加2:20
49以弗所书基督里的教会：在创立世界以前就蒙拣选的人，藉恩典因信得救，合为一个新人，并在生活与属灵争战中彰显基督。弗2:8-9
50腓立比书喜乐书信：狱中的保罗在基督里知足、喜乐，并以基督的降卑与升高为合一与谦卑的范本。腓2:5-6
51歌罗西书基督至上：一切丰盛的神性都有形有体地居住在基督里，信徒在他里面已经完全，不需哲学、规条或天使崇拜补充。西2:9
52帖撒罗尼迦前书年轻教会的盼望：在逼迫中信、望、爱的榜样，并对睡了的信徒与主的再来给予安慰。帖前5:16-18
53帖撒罗尼迦后书主的日子尚未来到：在逼迫中坚忍，在“不法的人”显露前不要动摇，也不要因末世热而懒惰。帖后3:3
54提摩太前书神家的规章：在以弗所抵挡假教训，建立长老与执事，规范敬拜与生活，持守“敬虔的奥秘”。提前2:5
55提摩太后书保罗的遗言：将所托付的善道交托忠心的人，坚守圣经，传道务要专心，那美好的仗我已经打过了。提后3:16-17
56提多书恩典教导人敬虔：在克里特设立长老，以纯正的道带出与之相称的善行。多3:5
57腓利门书福音改变关系：保罗为逃奴阿尼西母向主人腓利门说情，请他以弟兄而非奴仆接纳。门18
58希伯来书更美之约：基督比天使、摩西、亚伦更美，他是麦基洗德等次永远的大祭司，一次献上永远完全；所以不要退后，要坚持到底。来11:1
59雅各书活信心的书：真信心必有行为——在试炼、言语、贫富、谦卑与祷告中表明出来。雅2:26
60彼得前书寄居者的盼望：蒙拣选、被重生得活泼盼望的人，在苦难中顺服、行善，效法受苦的基督。彼前2:9
61彼得后书临别警告：在神的知识上长进，持守先知与使徒确定的话，抵挡假教师与讥诮主再来的人。彼后1:21
62约翰一书确据之书：神是光、神是爱；凭真理、顺命、彼此相爱三重试验，使信徒知道自己有永生。约一1:9
63约翰二书在真理中相爱：不可接待传否认基督道成肉身之教训的人。约二9
64约翰三书接待真理的同工：称赞该犹的款待，责备好为首的丢特腓，推荐低米丢。约三4
65犹大书为真道竭力争辩：警告偷着进来、把神的恩变作放纵的假教师，并以颂赞结束——神能保守你们不失脚。犹24-25
66启示录被杀羔羊的得胜：撤开帷幕，让受苦的教会看见宝座上的神与羔羊掌管历史，最终审判、新天新地、神与人同住。启21:3

2.66 卷记忆口诀总表

#书卷一句话口诀

2出埃及记救赎之书：耶和华施行大能救赎，把奴隶变为祭司的国度，在西奈立约，并亲自住在他们中间（会幕）。“灾逾海粮 · 律帐荣”（十灾—逾越节—过红海—吗哪—律法—会幕—荣耀）
3利未记圣洁之书：圣洁的神如何住在不洁的百姓中？——藉着献祭、祭司与赎罪日。“五祭二职 · 洁赎圣节”（五祭、祭司圣职、洁净、赎罪日、圣洁法典、节期）
4民数记旷野之书：不信的一代倒毙旷野，信实的神却保守新一代走到应许地门口。“两次数点 · 加低斯一败 · 铜蛇一举”
5申命记约的重申之书：摩西临终前在摩押平原向新一代讲道三篇，呼召他们“爱耶和华你的神”。“三篇讲道 · 一个示玛 · 两座山”
6约书亚记得地之书：神信实地实现对列祖的应许，带领以色列进入、征服并分配迦南地。“过河 · 绕城 · 分地 · 立约”
7士师记沉沦之书：没有王、各人任意而行的以色列陷入“犯罪—受压—呼求—拯救”的循环，而且一圈比一圈更深。“犯—压—呼—救—静”五步循环，十二士师“俄以珊 底基陀 睚耶以 以押参”
8路得记救赎至亲之书：黑暗士师时代里一段忠信与恩慈（hesed）的故事，引出大卫的家谱。“离—拾—求—赎”
9撒母耳记上王权之书（上）：从士师到君王的转折——撒母耳兴起，扫罗被立又被弃，大卫受膏而受苦。“撒—扫—大”三人一书
10撒母耳记下王权之书（下）：大卫作王、耶路撒冷成为京城、神与大卫立永约；随后大卫犯罪，家中刀剑不离。“七约十一罪”：第7章立约，第11章犯罪
11列王纪上从荣耀到分裂：所罗门建殿的高峰，王心偏离，国分为二；以利亚在巴力崇拜的黑暗中为耶和华作见证。“殿—裂—火”：所罗门建殿、国裂、以利亚天降火

20箴言敬畏耶和华是智慧的开端：父亲教导儿子在日常生活中行在智慧的道路上。“1-9父训，10-29箴集，30-31末篇”
21传道书“日光之下”的诚实之书：一切如烟似雾（hevel），唯有敬畏神、谨守他的诫命是人当尽的本分。“虚空×虚空，定时×永恒，结论：敬畏”
22雅歌歌中之歌：在婚约中男女纯洁而热烈的爱；更深层地，映照耶和华与他子民（基督与教会）的爱。“渴—婚—熟”三段
23以赛亚书旧约的“福音书”：圣者以色列的审判与安慰，从受苦的仆人到新天新地。“1-39审判（如旧约39卷），40-66安慰（如新约27卷）”
24耶利米书流泪先知的书：在犹大灭亡前四十年呼召悔改，宣告七十年被掳，并预告“新约”。“627蒙召，605第一次被掳，586城陷，31章新约”
25耶利米哀歌废墟上的哀歌：五首离合体诗，为耶路撒冷的毁灭哭泣，中心宣告“耶和华的慈爱永不断绝”。“五首哀歌，中间一线光（3:22–23）”
26以西结书神的荣耀离开与归回：被掳中的祭司先知看见宝座异象，宣告审判、复活与新圣殿。“荣耀离开（10）→ 枯骨复生（37）→ 荣耀归回（43）”

28何西阿书受伤丈夫之爱：先知娶淫妇歌篾，演出耶和华对不忠以色列的审判与不止息的爱。“娶—弃—赎：三章婚姻，十一章控诉”
29约珥书耶和华的日子：蝗灾是审判的预表，呼召撕裂心肠的悔改，并应许圣灵浇灌凡有血气的。“蝗—悔—灵—审”
30阿摩司书公义如大水滚滚：南国牧人到北国伯特利，宣告对富足而不义的宗教的审判。“3×4罪，5异象，1重建”
31俄巴底亚书旧约最短的书：以东因幸灾乐祸、协助攻击兄弟雅各而被审判；“国度要归耶和华”。“一章书：以东骄傲—锡安得国”
32约拿书逃跑的宣教士：神差约拿向仇敌之城尼尼微传悔改，显明神的怜悯临及外邦，也揭露先知自己的狭隘。“逃—祷—传—怒”
33弥迦书“谁像你？”——审判撒玛利亚和耶路撒冷，应许伯利恒出君王，并宣告神赦罪的怜悯。“3轮：审判+盼望；1问：谁像你？（弥迦名即“谁像耶和华”）”
34那鸿书尼尼微的第二篇信息：约拿时的悔改已过去，神必审判残暴的亚述——这是给犹大的“安慰”（那鸿=安慰）。“约拿：尼尼微悔改；那鸿：尼尼微灭亡（612）”
35哈巴谷书先知与神的对话：从“为什么？”到“义人必因信得生”，再到“我要因耶和华欢欣”。“问—答—问—答—诗；2:4 一句贯穿新约”
36西番雅书耶和华的大日临近：普世审判之后，神在锡安中间因你欢欣喜乐而歌唱。“日子—审判—歌唱”
37哈该书先建神的殿：四篇日期精确的信息，催促归回者停止只顾自己天花板的房屋，重建圣殿。“520年，4篇，1殿”
38撒迦利亚书小先知中的“启示录”：八个夜间异象、谦和的君王骑驴而来、被扎的牧人与终末的胜利。“8异象 + 2默示；受难周预言库”
39玛拉基书旧约的最后一句话：在冷淡的归回群体中，以辩论式问答揭露敷衍的敬拜，并预告“立约的使者”与以利亚的来临。“6场辩论：‘你们却说……’”
40马太福音君王之福音：耶稣是亚伯拉罕的后裔、大卫的子孙，应验律法和先知的弥赛亚君王，建立天国并差遣门徒使万民作门徒。“1家谱+5讲论+1大使命”
41马可福音仆人之福音：节奏急促（“立刻”40余次），展示神的儿子的权柄，并揭示他来是为了服事并舍命作多人的赎价。“前8章：他是谁？后8章：他为何而来？”
42路加福音人子与救主之福音：按次序详细考查，显明耶稣是寻找拯救失丧之人的救主，福音临到贫穷、妇女、外邦人与罪人。“1:4 确实；19:10 寻找；24:27 全经讲基督”
43约翰福音道成肉身之福音：七个神迹（记号）与七个“我是”，为要叫人信耶稣是基督、是神的儿子，并因信他的名得生命。“7记号 + 7我是 + 1目的（20:31）”
44使徒行传升天基督藉圣灵继续作工：福音从耶路撒冷、犹太全地、撒玛利亚，直到地极。“1:8 三圈：耶路撒冷→犹太撒玛利亚→地极（1-7 / 8-12 / 13-28）”
45罗马书福音的系统宣告：神的义藉信耶稣基督显明——罪、称义、成圣、拣选、生活，是宗教改革的“钥匙”。“罪—义—圣—选—活”

47哥林多后书软弱中的能力：保罗为自己的使徒职分辩护——瓦器里有宝贝，新约的执事是叫人得生的。“瓦器装宝贝；软弱显能力”

56提多书恩典教导人敬虔：在克里特设立长老，以纯正的道带出与之相称的善行。“1长老 2生活 3恩典”

60彼得前书寄居者的盼望：蒙拣选、被重生得活泼盼望的人，在苦难中顺服、行善，效法受苦的基督。“身份—生活—受苦”

63约翰二书在真理中相爱：不可接待传否认基督道成肉身之教训的人。“真理+爱；不越过”
64约翰三书接待真理的同工：称赞该犹的款待，责备好为首的丢特腓，推荐低米丢。“该犹好、丢特腓坏、低米丢有见证”
65犹大书为真道竭力争辩：警告偷着进来、把神的恩变作放纵的假教师，并以颂赞结束——神能保守你们不失脚。“争辩—警例—造就—颂赞”
